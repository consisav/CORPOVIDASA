# CORPOVIDASA — Versión Final

Proyecto web corporativo preliminar/final de CORPOVIDASA.

## Incluye
- Encabezado corporativo azul y dorado.
- Logo final separado en `images/CORPOVIDASA_logo_final.png`.
- Menú principal: Inicio, Nosotros, Servicios, Nuestras Empresas, Contacto.
- Menús desplegables para Servicios y Nuestras Empresas.
- Servicios al Migrante como servicio estratégico.
- Servicios al Migrante:
  1. Servicios Médicos
  2. Servicios Funerarios
  3. Descuentos especiales en Alojamientos
  4. Créditos especiales
  5. Construcción, remodelación o supervisión
  6. Nuevos emprendimientos
  7. Otros servicios
- Sección de empresas del grupo.
- Sección de valores y confianza.
- Contacto con:
  - +502 2219-3093
  - servicios@corpovidasa.com
  - corpovidasa.com
  - Avenida Hincapié 2-51, zona 13, Edificio “C”, Guatemala
  - Mapa de ubicación
- Diseño responsive para escritorio, tablet y celular.

## Importante
Los enlaces individuales de las empresas del grupo siguen como marcadores `#` hasta disponer de sus URLs oficiales.
El mapa incluido es una referencia de ubicación y puede ajustarse posteriormente a la ubicación exacta del inmueble.

Para visualizar:
1. Extraer el ZIP.
2. Abrir la carpeta en Visual Studio Code.
3. Abrir `index.html` en el navegador.
